# goit-algo-hw-06

## Опис проекту
Цей проект реалізує алгоритми пошуку шляху між містами України, використовуючи різні методи пошуку, такі як пошук у глибину (DFS) та пошук у ширину (BFS). Мета проекту - порівняти ефективність цих алгоритмів у контексті графів, що представляють міста та їх зв'язки.

## Результати
Алгоритм DFS досліджує глибину графа, тому він може знайти шлях, який йде глибше в графі перед тим, як повернутися назад. Це може призвести до довших шляхів.
Алгоритм BFS досліджує ширину графа, тому він знаходить найкоротший шлях у термінах кількості ребер між початковою та кінцевою вершинами. Тому шлях, знайдений BFS, зазвичай є коротшим або рівним за довжиною шляху, знайденого DFS.
